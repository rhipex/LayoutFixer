# LayoutFixer v1.0.0

First public release of LayoutFixer (based on the internally tested v3 build).

## Highlights

- Convert selected text between English and Russian keyboard layouts with Win + Shift.
- Leave Windows on the converted text's target keyboard layout.
- Avoid accidental DevTools opening from the internal clipboard shortcut.
- Preserve normal Win + Shift + key shortcuts.
- Tray icon with optional Run at Windows startup setting.
- Single-instance detection with a visible warning.
- Embedded A↔Я icon.

## Download

Download `LayoutFixer.exe` and run it. The executable is not code-signed, so Windows may display an Unknown Publisher or SmartScreen warning.
